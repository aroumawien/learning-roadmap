Open index.html in your browser.

Place your background images hero1.png and hero2.png in this folder, beside index.html, styles.css and script.js. Image files were not provided, so the page uses its existing base colour until you add them.

hero1.png is shown at the top. After the hero passes beneath the navigation, the background changes to hero2.png and stays behind all following sections. Scrolling back restores hero1.png.

Git & GitHub appears after CSS3, with both supplied SuperSimpleDev video links and a completion checkbox. Existing module IDs and saved progress are preserved.
